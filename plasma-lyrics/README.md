# wmPlayer Music KDE Plasma 歌词插件

通过 **D-Bus** 会话总线从 wmPlayer 播放器获取实时歌词，无网络端口依赖，零延迟，极低系统资源开销。

## 🌟 特性
- ⚡ **D-Bus 原生集成**：无需监听本地端口，自动响应播放器启动/退出。
- 🎤 **KRC 逐字卡拉OK动效**：支持酷狗 KRC 歌词高亮动画与平滑过渡。
- 📝 **LRC 标准歌词**：支持标准 LRC 歌词展示。
- 🎨 **自适应系统主题**：跟随 KDE Plasma 颜色风格（高亮色、文字色）。
- 🖱️ **便捷交互**：
  - **左键单击**：播放 / 暂停
  - **鼠标滚轮**：上一首 / 下一首
  - **中键点击**：开启 / 关闭桌面悬浮歌词

## 🚀 安装
```bash
./install.sh
```
安装完成后，在 KDE 任务栏或桌面右键点击“添加部件...”，搜索 **wmPlayer 歌词** 并拖拽到面板即可。

## 🗑️ 卸载
```bash
./uninstall.sh
```
